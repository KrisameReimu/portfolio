# Contact Page Rules

## Direction

Contact should be minimal, clear, and low-friction.

## Priority

- primary contact method
- professional links
- social / creative links if relevant
- short context on what Echo is open to

## Visual Rules

- minimal studio layout
- clear call-to-action
- low visual noise
- consistent card / button styling

## Avoid

- excessive form fields
- noisy social icon grids
- unclear contact hierarchy
- aggressive sales-style CTA copy
