# Home Page Rules

## Direction

Home should preserve the current illustrated scrapbook hero as the main brand anchor.

Below the hero, the page should become quieter and more structured.

## Content Priority

- who Echo is
- selected writing
- selected projects
- photography / multimedia
- awards / credentials
- contact path

## Visual Rules

- warm editorial archive
- large serif headings
- thin dividers
- paper-card surfaces
- restrained metadata
- no excessive decorative repetition

## Avoid

- repeating hero-level illustration density in every section
- too many competing cards
- generic SaaS feature grid
- unclear hierarchy after the hero
