# Videos Page Rules

## Direction

Videos should use cinematic visual cards.

The page should make preview frames and story context dominant.

## Priority

- strong preview frame
- title
- date
- location
- tool / device
- short description

## Visual Rules

- cinematic aspect ratios where appropriate
- compact metadata
- restrained card borders
- minimal decorative noise

## Avoid

- treating videos as generic blog cards
- excessive text before the preview
- heavy decorative frames
- autoplay behavior unless deliberately designed
