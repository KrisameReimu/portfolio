# Photos Page Rules

## Direction

Photos should use gallery-first minimalism.

The page should feel calmer than Home and Writing.

## Priority

- large images
- consistent ratios
- location / date / device metadata
- minimal captions
- clear grouping by theme or series

## Visual Rules

- image-first layout
- quiet canvas
- minimal UI chrome
- restrained captions
- generous whitespace

## Avoid

- heavy scrapbook decoration
- random image sizes without purpose
- overlaid text that damages image readability
- too many filters before the user sees images
