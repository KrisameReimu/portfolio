# Awards Page Rules

## Direction

Awards should use credential archive style.

The page should feel structured, credible, and calm.

## Priority

- award name
- institution
- date
- context
- evidence or related artifact if available

## Visual Rules

- compact archive cards
- clean timeline or grouped sections
- small metadata labels
- restrained highlight treatment

## Avoid

- over-celebratory visual language
- oversized trophy visuals
- vague achievement summaries
- mixing awards with unrelated project cards
