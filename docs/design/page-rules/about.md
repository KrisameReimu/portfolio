# About Page Rules

## Direction

About should connect the human identity and technical identity.

It should feel authored, specific, and concise.

## Priority

- current role and focus
- AI/software engineering identity
- multimedia and writing identity
- Hong Kong context
- selected tools and interests

## Visual Rules

- warm editorial layout
- compact fact sections
- personal but not sentimental tone
- restrained visual decoration

## Avoid

- generic résumé copy
- exaggerated personal branding language
- overly emotional tone
- long unstructured biography blocks
