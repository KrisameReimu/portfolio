# Reference: Apple Gallery Minimal

## Use For

- Photos page
- Videos page
- visual archive
- drone / Insta360 / street photography collections

## Extract

- gallery-white or warm-light canvas
- large image-first layout
- restrained navigation and UI chrome
- minimal captions
- consistent visual rhythm
- generous whitespace
- color should come from images, not decorative UI

## Avoid

- copying Apple product-page layout
- using Apple blue as the global identity
- using product gradients as UI chrome
- excessive centered marketing copy
- making Home look like an Apple product launch page

## Local Application

Use this reference to make Photos and Videos calmer than Home and Writing.

The UI should frame visual work, not compete with it.
