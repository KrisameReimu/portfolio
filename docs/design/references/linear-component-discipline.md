# Reference: Linear Component Discipline

## Use For

- badges
- metrics
- status labels
- project metadata
- timeline
- code-adjacent components
- compact technical cards

## Extract

- strict spacing rhythm
- compact component density
- subtle borders
- layered surfaces for hierarchy
- muted secondary text
- single accent for focus / active states
- mono font for technical metadata

## Avoid

- making the full site a dark command center
- using neon lime as the global identity
- dense dashboard layout on Writing or Photos
- harsh black background on editorial pages

## Local Application

Use Linear as component discipline only.

Suitable for Projects and technical metadata, not for the full site identity.
