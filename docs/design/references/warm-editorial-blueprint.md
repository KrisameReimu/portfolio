# Reference: Warm Editorial Blueprint

## Sources

- ElevenLabs
- Column

## Use For

- Home
- About
- Awards intro
- identity sections
- selected project introductions

## Extract

- warm paper-like canvas
- authored editorial tone
- blueprint-like thin lines
- calm institutional structure
- compact labels
- serif heading with quiet metadata
- mature personal archive feeling

## Avoid

- excessive decorative sketches
- turning every section into a poster
- generic AI startup aesthetics
- cold corporate dashboard styling
- visual noise below the main hero

## Local Application

Use this as the primary identity reference for the site.

It should mature the existing illustrated scrapbook identity without replacing it.
