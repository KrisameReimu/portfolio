# Reference: Premium Institutional Layout

## Use For

- Awards page
- credentials
- structured profile facts
- timeline sections
- contact / professional identity blocks

## Extract

- calm hierarchy
- slim borders
- restrained typography
- trustworthy spacing
- minimal visual noise
- precise metadata treatment

## Avoid

- finance-product visual language
- luxury branding clichés
- overusing black-and-gold styling
- making personal pages feel corporate

## Local Application

Use this to make credentials, achievements, and structured profile information feel mature and credible.
