# Reference: Minimal White Gallery

## Sources

- Mike Matas
- Apple, selectively

## Use For

- Photos
- Videos
- Multimedia overview
- article detail pages with strong visuals
- quiet visual archive pages

## Extract

- expansive white or warm-light canvas
- minimal UI chrome
- image-first layout
- strong text hierarchy
- quiet metadata
- generous whitespace
- content-first pacing

## Avoid

- dark gallery styling
- product-launch imitation
- decorative frames around every image
- making gallery pages feel like Projects
- overusing cards where direct content lists would be clearer

## Local Application

Use this as the primary low-noise visual reference for Multimedia pages.
