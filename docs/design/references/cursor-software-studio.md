# Reference: Cursor Software Studio

## Use For

- Projects page
- project detail pages
- AI system case studies
- technical capability sections

## Extract

- clean software panels
- screenshot frames
- compact metadata
- role / stack / status badges
- problem / solution / result structure
- restrained technical accent

## Avoid

- generic SaaS landing-page layout
- fake dashboard widgets
- meaningless metric cards
- excessive gradients
- turning personal identity into corporate software branding

## Local Application

Projects should prove engineering capability.

Each project should clearly show:

- what problem it solves
- what was built
- what technology was used
- what evidence or outcome exists
