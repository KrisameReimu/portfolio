# Site OS Model

## Direction

Site OS is the living layer of the personal website.

It represents what is current, experimental, planned, or evolving.

## Existing Content Sources

Current content files include:

- `apps/web/public/content/siteos/now.latest.json`
- `apps/web/public/content/siteos/roadmap.json`
- `apps/web/public/content/siteos/experiments.json`
- `apps/web/public/content/siteos/dashboard.public.json`

## Role

Site OS may support:

- Now
- Roadmap
- Experiments
- Lab
- public dashboard
- active projects
- current tools and setup

## Navigation Policy

Site OS does not need to be a top-level navigation item immediately.

Recommended placement:

- Now can be linked from About.
- Experiments can be linked from Lab or Home.
- Roadmap can be linked from About or a hidden Site OS route.
- Public dashboard can remain an experimental feature.

## Relationship to Other Axes

Writing owns long-form thinking.

Multimedia owns visual output.

Projects owns engineering proof.

Site OS owns current state and experiments.

## Design Direction

Site OS may be more experimental than Writing or About.

However, it should still follow the site's main identity and should not become a disconnected dashboard.

## Anti-Patterns

Do not let Site OS replace Projects.

Do not let Site OS make the top-level navigation too complex.

Do not expose half-finished experimental pages as primary navigation unless they are intentionally presented as experiments.

Do not use raw dashboard styling unless it supports the page's purpose.
