## 🐛 常见视觉问题 & 解决

### Canvas 不显示
**症状**: 右侧看不到粒子背景  
**解决**: 
```
1. DevTools 中检查 .wall-canvas 元素
2. 确认 z-index: 1, pointer-events: none
3. 检查 Canvas 宽高是否 > 0
4. 查看 Console 有无错误
```

### 文字显示不完整
**症状**: 卡片标题被截断不当  
**解决**:
```
1. 检查容器宽度 (应该 >= 140px)
2. 验证 -webkit-line-clamp: 2 是否生效
3. 确认字体大小 (0.9rem ≈ 14px)
```

### 动画卡顿
**症状**: 悬停时画面不流畅  
**解决**:
```
1. 打开 DevTools Performance
2. 查看 FPS 是否稳定在 60
3. 如果不稳定，检查其他 JavaScript 任务
4. 尝试关闭浏览器扩展
```

### 暗黑模式不生效
**症状**: 深色模式下颜色没有变化  
**解决**:
```
1. 检查 HTML 是否有 class="dark-mode"
2. 确认 .dark-mode & 选择器生效
3. 检查浏览器暗黑模式偏好设置
```
