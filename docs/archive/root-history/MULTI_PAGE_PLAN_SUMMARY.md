# 📋 跨页面优化计划总结

## 问题诊断

✋ **您的观察完全正确**：
- ✅ 主页已有独特风格和品质
- ❌ 其他页面还是"模板风" (Videos、Awards、Photography、Projects 等)
- ❌ 各页面没有差异化设计，感觉不统一

---

## 解决方案概览

### 核心策略

从模板化 → **"一致但有特色"** 的设计系统

**关键原则**:
1. **保持一致**: 所有页面都用 Glasmorphism、微交互等品质
2. **增加特色**: 每个页面有自己的主题色、布局、交互方式
3. **按需定制**: Videos=电影感、Awards=荣誉感、Photography=艺术感等

---

## 五大页面特色定位

| 页面 | 主题色 | 特色 | 重点体验 |
|------|--------|------|---------|
| Videos | 🔴 红色 | 电影院 | 播放按钮、视频时长、大幅封面 |
| Awards | 🟡 金色 | 荣誉殿堂 | 3D翻转卡片、金色光晕、等级徽章 |
| Photography | ⚫ 黑色 | 美术馆 | 白色画框、沉浸式Lightbox、Exif信息 |
| Projects | 💜 紫色 | 黑客工作室 | 代码高亮、Demo按钮、技术栈标签 |
| About | 🔵 蓝色 | 成长故事 | 竖向时间线、里程碑卡片、交替排列 |

---

## 实施方案

### 第 1 步：建立设计系统（1 小时）

创建两个新 SCSS 文件：

```
新增:
  src/_pageThemes.scss        ← 定义所有页面主题色
  src/_componentBase.scss     ← 定义通用组件模板
```

### 第 2-6 步：逐个优化页面（8-12 小时）

按优先级逐个改进：

1. **Videos** (1-2h) - 红色 + 暗背景 + 播放按钮
2. **Awards** (1-2h) - 金色 + 3D卡片翻转 + 光晕效果
3. **Photography** (2-3h) - 白色背景 + 画框 + 增强 Lightbox
4. **Projects** (2-3h) - 紫色深灰 + 代码高亮 + Demo并排
5. **About** (1-2h) - 蓝色 + 竖向Timeline + 卡片
6. **全局测试** (1h) - 深色模式、响应式、性能

### 第 7 步：质量保证（1 小时）

- 构建通过: `npm run build`
- 响应式设计: 桌面/平板/手机
- 深色模式兼容
- 无性能问题
