# Archive Docs

This directory stores historical implementation artifacts that are useful for reference but should not define the current repository structure.

## Use This Folder For

- completion reports
- redesign proposals
- handover notes
- one-off implementation summaries
- temporary planning documents that are no longer active operating docs

## Current Layout

- `root-history/`: legacy markdown files moved out of the repository root to keep root discoverable

If a document is still needed for active day-to-day operations, move or rewrite it under `docs/` instead of leaving it archived.
